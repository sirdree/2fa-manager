📘 Google OAuth Setup Guide

Step-by-Step Instructions

1. Create Google Cloud Project

  1. Go to Google Cloud Console
  2. Click "Select a Project" → "New Project"
  3. Project name: 2FA Manager
  4. Click "Create"

2. Enable Google Drive API

  1. In your project, go to "APIs & Services" → "Library"
  2. Search for "Google Drive API"
  3. Click on it → Click "Enable"

3. Configure OAuth Consent Screen

  1. Go to "APIs & Services" → "OAuth consent screen"
  2. User Type: Select "External"
  3. Click "Create"
  4. App name: 2FA Manager
  5. User support email: Your email
  6. Developer contact: Your email
  7. Click "Save and Continue"
  8. On Scopes page, click "Add or Remove Scopes"
  9. Add scope: https://www.googleapis.com/auth/drive.appdata
  10. Click "Update" → "Save and Continue"
  11. Add your email as test user
  12. Click "Save and Continue"

4. Create OAuth Client ID

  1. Go to "APIs & Services" → "Credentials"
  2. Click "Create Credentials" → "OAuth client ID"
  3. Application type: "Web application"
  4. Name: 2FA Manager Extension
  5. Authorized redirect URIs: Add https://YOUR_EXTENSION_ID.chromiumapp.org/
  6. Click "Create"
  7. Copy the Client ID (format: 123456789.apps.googleusercontent.com)

5. Paste Client ID Above

Copy the Client ID and paste it into the "OAuth Client ID" field on this page, then click "Save Client ID".

⚠️ Important

• Make sure to use "Web application" as the OAuth client type
• The redirect URI must match your extension ID exactly
• Add your Google account as a test user in OAuth consent screen
